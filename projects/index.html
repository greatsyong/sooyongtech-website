Projects

My robotics projects are organized into three technical areas: Vision & Sensor Fusion, Control Systems, and Reinforcement Learning. The work progresses from fundamental implementation and analysis to robotic application, experimental evaluation, and engineering decision-making.

01 · VISION & SENSOR FUSION

Vision & Sensor Fusion

Robotic perception projects focused on extracting useful information from visual and range sensors, then combining heterogeneous measurements into a common spatial representation.

VISION PROJECT 01 · REAL-TIME PERCEPTION

Real-time object detection, persistent tracking, and instance segmentation using GPU-accelerated deep-learning models, with quantitative evaluation of inference latency, processing speed, and perception performance.

02 · CONTROL SYSTEMS

Control Systems

Control projects progressing from state estimation and mathematical controller design to implementation on mobile robots and manipulators, followed by comparative evaluation of performance, robustness, computational cost, and practical suitability.
