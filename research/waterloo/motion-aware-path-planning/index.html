Motion-Aware Path Planning
with a Summit Mobile Robot

Experimental support for motion-aware path-planning research using a Summit mobile robot, with emphasis on physical validation of path choices under robot motion and speed constraints.

Project Context

When the shortest path is not the fastest path

The research investigated path selection that considers not only geometric distance, but also how quickly a mobile robot can safely traverse a route.

A narrow or sharply turning path may be geometrically shorter, but can require substantial speed reduction. A wider and smoother route may be longer in distance while still producing a shorter traversal time because the robot can maintain a higher velocity.

Planning Concept

Path geometry and robot motion capability

The planning approach considered the relationship between route geometry and the mobile robot's achievable motion.

Wider passages and smoother turns can allow the robot to sustain higher speed, while constrained spaces and sharp changes in direction can reduce feasible velocity.

Path-selection factors

  • Geometric path length
  • Available free-space width
  • Turn severity
  • Robot motion limits
  • Achievable travel speed
  • Overall traversal efficiency
