Project Overview

Multi-floor navigation as an integrated robotics task

The collaborative system was developed around a practical scenario: navigate from a laboratory on the third floor to the elevator, interact with the elevator controls, transition between floors, and continue navigation toward the first-floor RoboHub.

System Architecture

Navigation, perception, manipulation, and task control

The collaborative system connected the Summit XLS navigation stack, WAM manipulator, ZED camera, task-control software, inverse kinematics, and networked computers.

MOBILE NAVIGATION

Summit XLS

ROS navigation and move_base were used for localization, goal execution, and autonomous movement within the mapped environments.

PERCEPTION

ZED + ArUco

Vision-based marker detection was used by the elevator interaction subsystem to estimate the pose required for button pressing.

MANIPULATION

WAM 7-DOF

The WAM manipulator subsystem used inverse kinematics and pose calibration for physical interaction with the elevator controls.

TASK CONTROL

ROS task orchestration

A task-control layer coordinated navigation, perception, manipulation, and elevator-interaction stages across the integrated system.

Collaborative Subsystem

Vision-guided elevator interaction

The elevator-interaction subsystem was developed by other members of the research team. It combined perception and manipulation within a consistent spatial reference, using ArUco markers as visual landmarks for estimating the target pose.

The WAM manipulator used the estimated pose and an inverse-kinematics solution to approach and press the elevator control. This subsystem was integrated with the Summit XLS navigation workflow.

Interaction pipeline

  • Detect ArUco marker
  • Estimate target pose
  • Transform pose into robot/manipulator frame
  • Solve WAM inverse kinematics
  • Execute button-press motion
Calibration & Debugging

Coordinate-frame alignment

Reliable system integration required consistent camera, robot, and manipulator coordinate frames.

Frame-alignment issue

System testing indicated that the camera frame and the other system frames were not consistently aligned, introducing pose offsets during manipulation.

Calibration approach

Base ArUco markers were added to the Summit platform to establish a visual reference, and larger markers were used to improve pose-estimation reliability.

System Integration

Practical robotics troubleshooting

Integrating multiple robotic subsystems required debugging beyond navigation and manipulation algorithms.

Communication, networking, planner behavior, coordinate alignment, and hardware recovery all affected whether the integrated demonstration could operate reliably.

Issues addressed

  • CAN communication failure
  • Summit control loss
  • Remote-PC network disconnection
  • Router and network reconfiguration
  • Local-planner oscillation near the goal
  • Pose-estimation and frame-alignment errors
